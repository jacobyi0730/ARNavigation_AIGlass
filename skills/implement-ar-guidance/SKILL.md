# AR 안내 구현

## 준비

1. 배정된 `docs/tasks/stage-XX.md` 작업 ID, 기획서 5.1절과 `rg`로 찾은 관련 기기 제약만 읽는다.
2. 단계 0에서 확정한 AR 렌더링 계층과 실제 프로젝트 의존성을 확인한다.
3. 내비게이션 엔진이 제공하는 상대각, 목표 유형, 거리, 품질 상태 계약을 확인한다.

## 세션과 평면

- 카메라 권한과 ARCore 준비 완료 후에만 세션을 생성한다.
- Compose/Activity 수명주기에 맞춰 session과 렌더링 뷰를 pause, resume, destroy 한다.
- 수평 상향 평면만 바닥 후보로 사용하고 추적 품질을 함께 평가한다.
- 평면 미인식 또는 추적 손실 시 마지막 방향을 사실처럼 고정하지 말고 인디케이터를 숨긴다.
- ARCore 예외를 앱 종료 대신 명시적 UI 상태로 변환한다.

## 인디케이터

- 모델의 축, 단위, 원점과 바닥 접점을 기록하고 렌더러 좌표계에 맞춘다.
- 카메라 전방 약 1.5 m의 안정적인 바닥 위치에 배치하고 목표 방향으로 회전한다.
- 0°/360° 경계를 고려한 보간을 사용해 떨림과 순간 이동을 줄인다.
- 경유지와 목적지는 색상뿐 아니라 텍스트 또는 형태로 구분한다.
- 모델과 텍스처를 캐시하고 debug 빌드에서 FPS를 측정한다.
- 실제 통행 가능 경로나 장애물 회피를 보장하는 것처럼 표현하지 않는다.

## 검증

- 지원 실기기에서 세션 진입·이탈·재진입을 반복한다.
- 다양한 바닥과 조도에서 평면 탐지, 추적 손실·회복을 확인한다.
- 제자리 360° 회전과 동서남북 목표에서 방향 유지 여부를 기록한다.
- 경유지 전환과 목적지 도착 시 모델 스타일과 UI 상태를 확인한다.
- 목표 30 FPS와 카메라/세션 리소스 누수를 확인한다.

실기기 검증 없이 AR 완료로 표시하지 않는다. 기기별 제약, 좌표계 실수 또는 추적 실패는 `$record-retrospective`로 기록한다.
