# MVP 완료 정의

- 상위 인덱스: [TodoList](../TodoList.md)

이 문서는 최종 통합과 릴리스 판정 때만 읽는다.

- [ ] [DOD-01] 사용자가 현재 위치 중심 지도에서 목적지 한 개를 지정할 수 있다.
- [ ] [DOD-02] 사용자가 복수 경유지를 순서대로 추가하고 개별 삭제할 수 있다.
- [ ] [DOD-03] 취소 시 편집 내용이 반영되지 않고 AR 화면으로 복귀한다.
- [ ] [DOD-04] 시작 시 현재 위치가 시작점으로 저장되고 AR 안내가 시작된다.
- [ ] [DOD-05] AR 인디케이터가 인식된 바닥면에서 현재 안내 지점 방향을 가리킨다.
- [ ] [DOD-06] 경유지를 추가 순서대로 도착 처리한 뒤 목적지로 안내한다.
- [ ] [DOD-07] AR↔지도 전환 후에도 마커와 진행 상태가 유지된다.
- [ ] [DOD-08] 권한, 위치, 방향 센서, AR 추적 품질 문제를 크래시 없이 안내한다.
- [ ] [DOD-09] 화면 회전과 foreground/background 전환에서 세션과 리소스가 안전하게 유지된다.
- [ ] [DOD-10] 핵심 단위/UI 테스트와 기획서의 인수 조건이 모두 통과한다.
- [ ] [DOD-11] 지원 대상 실제 기기에서 30 FPS 목표와 야외 방향 안내를 검증한다.
- [ ] [DOD-12] API 키, 개인정보, 라이선스 및 빌드 문서가 릴리스 기준을 충족한다.
