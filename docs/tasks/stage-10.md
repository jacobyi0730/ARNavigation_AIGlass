### 10.1 안내 정보 오버레이

- [ ] [S10-T001] 길찾기 전 AR 대기 화면과 지도 버튼을 구현한다.
- [ ] [S10-T002] 길찾기 중 `경유지 n/N` 또는 `목적지`를 표시한다.
- [ ] [S10-T003] 현재 안내 지점까지의 거리를 m/km 형식으로 표시한다.
- [ ] [S10-T004] GPS 낮은 정확도, 나침반 보정 필요, 평면 탐색, 추적 손실 배너를 구현한다.

### 10.2 방향 인디케이터 연결

- [ ] [S10-T007] 내비게이션 엔진의 상대 방향을 렌더러 회전값으로 변환한다.
- [ ] [S10-T008] 인디케이터가 목표 절대 방향을 유지하도록 AR 카메라 자세와 센서 방위를 결합한다.
- [ ] [S10-T009] 상대각 갱신에 원형 보간을 적용해 떨림을 줄인다.
- [ ] [S10-T010] 새 바닥 평면이 잡혀도 모델이 불필요하게 순간 이동하지 않게 안정화한다.
- [ ] [S10-T011] 경유지는 파란색, 목적지는 녹색 등 확정된 스타일로 변경한다.
- [ ] [S10-T012] 품질 저하 중에는 잘못된 3D 방향을 숨기거나 낮은 신뢰도로 표시한다.
- [ ] [S10-T013] 선택 정책에 따라 평면 미인식용 2D 보조 화살표를 구현한다.

### 10.3 도착 흐름

- [ ] [S10-T014] 경유지 도착 시 완료 피드백 후 다음 안내 지점으로 자동 전환한다.
- [ ] [S10-T015] 마지막 경유지 뒤 목적지로 정상 전환한다.
- [ ] [S10-T016] 목적지 도착 시 도착 메시지와 완료 UI를 표시한다.
- [ ] [S10-T017] 완료 확인 후 세션을 `IDLE`로 초기화하고 위치/센서 업데이트를 정리한다.
