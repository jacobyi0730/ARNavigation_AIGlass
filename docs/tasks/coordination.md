# 멀티 에이전트 병렬 작업 체크리스트

- 상위 인덱스: [TodoList](../TodoList.md)

병렬 작업을 실제로 수행할 때만 읽는다. 공통 계약이 확정되고 수정 경로가 겹치지 않는 트랙만 병렬화한다.

## 기반 기능 병렬 구간

- [ ] [COORD-01] 시작 전 공유 데이터 타입과 인터페이스를 공용 작업 트리에 먼저 반영한다.
- [ ] [COORD-02] 각 트랙은 자신의 Fake 구현과 단위 테스트를 함께 작성한다.
- [ ] [COORD-03] 통합 담당자가 단계 6 전에 계약 변경과 충돌을 정리한다.

## 지도·AR 화면 병렬 구간

- [ ] [COORD-04] 지도와 AR 작업은 단계 7에서 확정한 화면 전환 계약을 고정해 사용한다.
- [ ] [COORD-05] 3D 모델 담당자는 파일명, 축, 단위와 라이선스를 AR 트랙에 전달한다.
- [ ] [COORD-06] 지도와 AR 완료 후 단일 통합 담당자가 단계 10~11을 수행한다.

## 병렬 작업 완료 기준

- [ ] [COORD-07] 각 트랙이 수정한 파일 범위와 공개 계약 변경을 기록한다.
- [ ] [COORD-08] 각 트랙의 빌드와 관련 테스트가 독립적으로 통과한다.
- [ ] [COORD-09] 임시 mock, fake와 코드 TODO를 통합 전 목록화한다.
- [ ] [COORD-10] 공통 파일 충돌을 해소한 후 전체 회귀 테스트를 수행한다.
