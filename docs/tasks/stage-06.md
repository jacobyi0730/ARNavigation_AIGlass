# 단계 6: 내비게이션 계산 엔진

- 선행 단계: 2, 4, 5의 계약
- 기본 스킬: $implement-navigation-engine
- 상위 인덱스: [TodoList](../TodoList.md)

> 이 파일만 읽어 단계 6 작업을 수행한다. 전체 진행률은 `..\..\tools\todo-status.ps1`로 조회한다.


### 6.1 거리·방위 계산

- [ ] [S06-T001] 두 좌표 사이 지표면 직선거리 계산기를 구현한다.
- [ ] [S06-T002] 현재 좌표에서 목표 좌표까지의 초기 절대 방위각을 구현한다.
- [ ] [S06-T003] `목표 방위각 - 기기 방위각` 상대각을 -180°~180°로 정규화한다.
- [ ] [S06-T004] 단위와 반올림 정책에 따른 거리 포매터를 구현한다.
- [ ] [S06-T005] 국제 날짜 변경선, 동일 좌표, 0°/360° 경계 테스트를 작성한다.

### 6.2 안내 대상 선택

- [ ] [S06-T006] 미도착 경유지 중 순번이 가장 빠른 지점을 선택한다.
- [ ] [S06-T007] 남은 경유지가 없으면 목적지를 선택한다.
- [ ] [S06-T008] 도착/건너뜀 처리된 지점은 다시 선택하지 않는다.
- [ ] [S06-T009] 목적지까지 완료된 경우 `ARRIVED`로 전환한다.
- [ ] [S06-T010] 목적지와 시작점이 도착 반경 안이면 시작 직후 도착 처리한다.

### 6.3 도착 판정

- [ ] [S06-T011] 목표와의 거리가 10 m 이내인지 판정한다.
- [ ] [S06-T012] 반경 안에 3초 연속 머문 경우에만 도착으로 확정한다.
- [ ] [S06-T013] 유지 시간 중 반경 밖으로 벗어나면 타이머를 초기화한다.
- [ ] [S06-T014] 낮은 정확도 또는 오래된 위치는 도착 판정에 사용하지 않는다.
- [ ] [S06-T015] 경유지 도착 시 다음 지점으로 한 번만 전환되도록 멱등성을 보장한다.

### 6.4 품질 통합

- [ ] [S06-T016] 위치와 방향 품질을 종합해 `NAVIGATING/PAUSED_QUALITY`를 결정한다.
- [ ] [S06-T017] 품질 저하 중에는 오래된 방향 인디케이터를 확정적으로 표시하지 않는다.
- [ ] [S06-T018] 품질 회복 시 최신 위치·방향을 받은 후 안내를 재개한다.

### 단계 6 테스트

- [ ] [S06-T019] 경유지 0개/1개/여러 개의 전체 진행 테스트를 작성한다.
- [ ] [S06-T020] 도착 반경 경계 및 GPS 튐 시나리오를 가상 시간으로 테스트한다.
- [ ] [S06-T021] 완료된 경유지가 재선택되지 않는 회귀 테스트를 작성한다.
- [ ] [S06-T022] 위치/방향 품질 저하와 회복 전이 테스트를 작성한다.
