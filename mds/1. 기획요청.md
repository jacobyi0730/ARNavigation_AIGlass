안드로이드 기반 AR 예제

#역할
너는 20년차 Android 개발자이고, ARCore, GPS기반의 프로젝트를 다수 진행한 경험이 있는 앱 개발자야.

#배경
ARCore의 기본기능(클라우드포인트/평면, AR Plane)과 GPS/나침반으로 목적지 방향을 알려주는 앱을 기획하고싶어. 

#요구사항
- AR화면(AR 카메라 화면)과 지도화면(Google Map)으로 구성
- 아래 세부내용을 기반으로 기획서를 작성해줘. 부족한 부분이 있으면 보강해줘.

#세부사항
##AR화면 세부사항
- 하단에 지도 버튼을 누르면 지도화면으로 전환되어야해. 만약, 길찾기가 시작된 상태라면 하단의 지도버튼을 누르면 지도화면으로 넘어가서 길찾기를 시작할때의 마커들(시작,경유지,목적지)을 다시 볼 수 있어야해.
- 현재 길찾기 중이라면 AR카메라가 인식한 바닥면에 지도화면에서 마킹한 경유지 혹은 목적지 마커중 현재위치에서 가장 가까우면서 목적지 방향의 마커를 향하는 3D 인디케이터를 그려줘.

##지도화면 세부사항
- 지도화면에서는 GPS를 이용해서 현재위치를 기반으로 GoogleMap 화면이 보여져야해.
- 하단에 목적지 버튼을 누르고 화면을 터치하면 목적지 마크를 표시해야해.
- 하단에 경유지 버튼을 누르고 화면을 터치하면 경유지 마커를 계속 추가할 수 있고, 생성된 경유지 마크를 터치하면 해당 경유지 마커는 삭제 되어야해. 하단의 경유지 버튼을 누르면 경유지 추가가 완료되어야해.
- 하단에 시작 버튼을 누르면 AR화면으로 전환되면서 시작마커->경유지마커->목적지마커로 이어지는 길찾기가 시작되어야해.
- 하단에 취소 버튼을 누르면 아무것도 하지않고 AR화면으로 전환.
